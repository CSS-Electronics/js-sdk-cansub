CANsub JavaScript/TypeScript SDK - Examples

Open an example, enter your CANsub URL (e.g. https://2c08fbb4-usb.local) and connect a channel in the sidebar.
To test without a vehicle or machine, connect CAN1 to CAN2 and replay sample-data/canmod-temp.csv on CAN2 (see the README).

  • starterThe template for your own app: Sidebar, signal picker and a table of live signal values.
  • signal-chartDecode signals with DBC files and plot them live, from any message and channel.
  • frame-tableThe newest raw CAN frames of every connected channel.
  • message-summaryOne row per CAN ID with frame count, frame rate and the latest data.
  • csv-filesExport the stored frames as CSV and import CSV files, in webCAN's format.
  • filtered-traceA time-sorted trace across channels, filtered by CAN ID.
  • raw-frame-viewerThe minimal integration without the UI kit: stream frames and show the most recent one.
  • device-configConfigure the device through the REST API only, without the UI kit: device info, time sync and bit rate.
  • bitrate-autodetectFind the bit rate of an unknown bus, without the UI kit: REST client and WebSocket client together.

Your own app is just another folder: Copy examples/starter/ to examples/my-app/ and open /examples/my-app/. npm run build -- my-app turns it into one self-contained file, dist/my-app.html.
